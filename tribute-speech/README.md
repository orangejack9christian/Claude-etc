# Tribute speech: Mrs. Teske

- `speech.md`: full speech in outline order (AG, credibility, purpose, preview, 3 main points, review, full circle, closure). About 550 words, which is about 4¼–4½ minutes at a slow pace.
- `Tribute_Speech_Mrs_Teske.pptx`: 5 slides (Intro, Caring, Dedicated, Ready for High School, Thank You). Each slide has the speech text in its speaker notes. Every gray box is a photo slot: right-click it → **Replace image**. Opens in Google Slides with File → Import slides, or by uploading it to Drive.
- `notecards.md`: 5 notecards, one per slide, using the same symbols and Spots A/B/C as the Bermuda cards.
- `build_slides.js`: source for the deck. Rebuild with `NODE_PATH=<folder with pptxgenjs + sharp> node build_slides.js`.
