How it learned

The network started knowing nothing: every weight was zero. It played game after game, and after each one it nudged its weights so its prediction for every position moved toward what actually happened next (temporal-difference learning). Each button below replays a real game it played at that stage of training, with no search, just the network. Replays roll on to the next stage by themselves.

Inside the engine

Like a modern chess engine, it has two halves: a learned evaluation that judges a position at a glance, and a search that looks ahead to check that judgement. The evaluation is an n-tuple network, the kind of network behind the strongest 2048 programs: shallow and very wide, with a learned weight for every arrangement of tiles in each of four 6-cell windows.

The network's four windows

× 8 symmetries

Each window is also applied in all 8 rotations and reflections of the board, with shared weights, so the network sees 32 overlapping views. The value of a position is the sum of the 32 weights those views point to: the points it expects to still earn from there.

The search is expectimax. For each move it averages over every square the next tile could land on (a 2 nine times in ten, a 4 otherwise), takes its best reply to each, and so on. Like a chess engine it deepens one level at a time until its time is up, remembers positions it has already worked out, and skips branches too unlikely to matter.
